# 游戏素材界面（v0.92）

本轮只调整辅助器的显示素材和悬浮交互，不更改游戏内的外观、背包或账号解锁状态。卡框与插画继续沿用已有游戏资源；主面板改用游戏菜单的金属边框、棕色底、按钮、勾选框和标题字体，卡牌与推荐条目收紧间距。

Android 展开时使用不接收触摸的原生棕色底板，游戏菜单边框通过 NinePatchDrawable 绘在同一个 View 上。原始 256×128 Sprite 使用左右 64、上下 48 像素的九宫格切片，中心留透明，固定四角约 11×8 dp；边框与底板一同按屏幕宽度的 56% 更新。这样避免透明 WebView 缩放后仍保留旧尺寸的背景／边框绘制层。收起和悬浮时整块原生底板隐藏；浏览器预览使用 CSS 背景与边框层，Android 隐藏这层，避免重复竖边；内容容器不再绘制外框、阴影或位移动画，防止旧尺寸的网页装饰层残留在面板中间。

## 素材来源与重建

运行 `python mobilebpp/tools/extract_theme.py`。依赖见 `tools/requirements.txt`，输入为本机 `TheBazaar.apk` 和只读 `work/GameData.db`。结果保存在 `web/theme/`，逐项来源、模型、纹理、尺寸与原始 Sprite 九宫格边距见 `web/theme-report.json`。

- 94 款地毯：当前 APK 的 `carpet_*_assets_all.bundle`，共用 `carpet_common` 中的 Carpet mesh，以原始 X/Z 几何和 UV 投影，保留轮廓与约 4.8538 的实际宽高比。排除没有独立插画的旋转 prefab 引用，不从商城下载缺失资源。
- 地毯名称优先使用当前游戏 collectibles 表的 Name，未匹配的保留资源名称；未伪造中文译名。设置显示的是辅助窗主题，不是领取或更改账号的商城外观。
- 五档技能框：`skills_assets_all.bundle` 中的 SkillFrame_<quality>_SM 模型及 SkillFrame_Token_TD／传奇原始漫反射贴图，保留各品质不同的轮廓和宽高比；图标置于内部圆形区域。
- 19 张菜单 Sprite：原始 UI atlas、按钮与设置 prefab；边框使用原始九宫格边距，避免整体拉伸四角。
- 停靠提示：用原始圆按钮底、框和返回图标组合为 dock.webp。仅拖拽时在左侧中央出现，不接收触摸，不铺整条黄色底。
- 标题字体：游戏 fonts_cn 包的 NotoSerifSC-SemiBold，转 WOFF2 后本地随 APK 打包。正文保留系统中文字体。

素材仅供本地辅助窗使用。119 张导出 WebP 均已实际解码检查；不将模型贴图中的特效 Alpha 当作插画透明度。

## 手机交互

悬浮窗只显示紧凑卡面及选中的游戏地毯。轻点只在下方显示／收起该阵容的技能，不打开完整面板；技能不显示名称和说明，使用相应品质的原始技能框。完整阵容详情保留在十胜列表和参考阵容入口。

长按 350ms 后可从窗内任意位置移动，采用 Android raw 屏幕坐标。拖至左侧中央松手恢复收起入口；原地长按而没有移动不会误触收回。展开技能时只增大辅助窗自身高度，外部触摸仍交给游戏。

设置中的“悬浮窗地毯”提供全部 94 款缩略图。选择写入 WebView 本地存储 bazaarBot.carpet，升级和下次启动保留；图库刷新保留滚动位置。
